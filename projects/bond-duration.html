Bond Duration & Interest-Rate Analysis

Summer 2026

Overview

A self-study project on how bond prices respond to changes in interest rates. It is still in progress and is not a completed project.

What has been done

  • Set up an Excel sheet covering Treasuries and corporate bonds.
  • Calculated duration for each bond.
  • Ran simple +100 and −100 basis-point interest-rate shocks to estimate price changes.

Not yet done

  • The mortgage-backed securities (MBS) component.
  • Credit stress testing.
This page summarizes the work only. It does not include the underlying holdings, results, or a downloadable workbook.
